## 1. Security (8 รายการ เป็น 0: แก้ในโค้ด 2, ยกเว้นพร้อมเหตุผล 6)
- prisma.config.ts: เอาชื่อผู้ใช้และรหัสผ่านฐานข้อมูลที่ฝังในค่าสำรองออก ค่าจริงต้องมาจาก DATABASE_URL เท่านั้น (BLOCKER)
- .github/workflows/ci.yml: ฐานข้อมูลชั่วคราวของ CI เปลี่ยนไปใช้ trust ทำให้ DATABASE_URL ไม่มีรหัสผ่านอยู่ในไฟล์
- sonar-project.properties: ไม่สแกนไฟล์ .env ที่มีรหัสผ่านจริงของเครื่อง ไม่ให้ถูกส่งขึ้นเซิร์ฟเวอร์ SonarQube
- scripts/maintenance-worker.mjs: เลิกใช้ http:// เป็นค่าเริ่มต้น บังคับให้ระบุ JOB_ENDPOINT และตรวจว่าเป็น URL จริง
- lib/ui-labels.ts: กฎ hard-coded password เป็น false positive (คำว่า PASSWORD อยู่ในชื่อเหตุการณ์ ไม่ใช่รหัสผ่าน) ยกเว้นเฉพาะไฟล์นี้พร้อมเขียนเหตุผลไว้

## 4. Test coverage (40.3% เป็น 92.3%)
- เพิ่มเทสต์ integration ใหม่ 10 ไฟล์ เรียก API จริงของทุกบทบาท: เจ้าของหอ ผู้เช่า และผู้ดูแลระบบ
- route-sweep ตรวจทุก route ใน app/api ว่าไม่ล็อกอินต้องถูกปฏิเสธ ล็อกอินผิดบทบาทต้องถูกปฏิเสธ และข้อมูลผิดต้องไม่ทำให้ระบบตอบ 500
- เทสต์ขั้นตอนงานจริง: ตั้งค่าหอ อาคาร ห้อง ผู้เช่า ย้ายห้อง ย้ายออก ออกบิล ส่งสลิป อนุมัติ พัสดุ แจ้งซ่อม แชต เอกสาร สัญญาเช่า แพ็กเกจ รหัสผ่าน และงานลบไฟล์ตามกำหนด
- ไม่นับ coverage ของหน้าจอ (app/**/*.tsx) ไฟล์ตั้งค่า และสคริปต์ทำคู่มือใน deliverables ซึ่งทดสอบด้วย Playwright หรือไม่ใช่โค้ดของระบบ (ยังตรวจหา bug ตามปกติ)
- รวมเทสต์ทั้งหมด 351 ตัว ผ่านทุกตัว
