# รายการสื่อจริงที่ต้องได้รับจากบริษัท

ห้ามนำภาพตัวอย่างหรือภาพที่สร้างขึ้นมาอ้างว่าเป็นสินค้า ทีมงาน ลูกค้า หรือ
ผลงานจริงของบริษัท สื่อทุกไฟล์ต้องได้รับการยืนยันสิทธิ์และเนื้อหาจากเจ้าของบริษัท
ก่อนเผยแพร่

## ไฟล์ที่ต้องเตรียม

- โลโก้ต้นฉบับ SVG หรือ PNG โปร่งใสความละเอียดสูง
- ภาพ Hero แนวนอนอย่างน้อย 2400×1350 px
- ภาพบริษัท สำนักงาน รถบริการ และทีมงานที่ได้รับอนุญาต
- รูปสินค้าจากผู้ผลิตหรือผู้จัดจำหน่ายที่บริษัทมีสิทธิ์ใช้งาน
- รูปปกสินค้าสัดส่วน 4:3 และภาพแกลเลอรีของแต่ละรุ่น
- Catalog PDF ฉบับล่าสุดที่อนุญาตให้เผยแพร่
- รูปผลงานก่อน–หลัง โดยไม่มีใบหน้า ป้ายทะเบียน เอกสาร หรือข้อมูลลูกค้าที่ไม่ควรเปิดเผย
- รูปปกผลงานสัดส่วน 16:10 และแกลเลอรี 4–12 รูปต่อโครงการ
- รูปปกข่าวและบทความสัดส่วน 16:9
- พิกัด Google Maps และ URL ของ LINE Official/Facebook ที่ยืนยันแล้ว

## Naming convention

ใช้ชื่อภาษาอังกฤษตัวพิมพ์เล็ก เช่น `daikin-smash-ii-cover.webp` และ
`office-renovation-01.webp` หลีกเลี่ยงชื่อบุคคล เลขที่โครงการ หรือข้อมูลภายใน
ในชื่อไฟล์และ metadata

## ก่อนนำเข้าระบบ

1. เจ้าของบริษัทยืนยันความถูกต้องและสิทธิ์เผยแพร่
2. ลบ EXIF/GPS และข้อมูลส่วนบุคคลที่ไม่จำเป็น
3. ตรวจว่าไม่มีข้อมูลลูกค้าหรือสถานที่ส่วนบุคคลปรากฏโดยไม่ได้รับอนุญาต
4. เก็บไฟล์ต้นฉบับในพื้นที่ของบริษัท แล้วให้ระบบสร้าง WebP/AVIF และ thumbnail
5. กรอก alt text ภาษาไทยที่บอกสาระของภาพอย่างกระชับ
